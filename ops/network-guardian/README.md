# Owned network Guardian source packages

These versioned operational artifacts have a separate installation and standing
authority from the Core binary. A Core image build does not install or activate
them. CI replays public historical evidence and simulates native boundaries; it
cannot qualify a host, a current network window, Guest readiness or capacity.

`g6pair-boot-v2` corrects the current15 reader's initializer selection after a
reboot. The initial boot retains its immutable Core262/R43 initializer. A later
boot must authenticate the exact current controller lifetime's original full120
record, recompute its original journals, and compare the resulting initializer
to the current native 47-object handle structure. The fresh finite512 tail,
closing journal read, transport reads and native kernel observation still own
the current15 result. Historical full120 is never cached current health.

`g6pair-boot-v2/PACKAGE.json` and `SHA256SUMS` bind all eight source modules and
the two future Cold/Guardian unit files. The unchanged coverage, journal and
tail reducers, original kernel method, controller source/config, Core image
pair chain and recovery/budget methods retain their original bytes. The
dedicated G6 predecessor authority retains the original source/standing tuple
on every old record, including the same per-boot three-recovery budget and
fixed full120. No record is rewritten and no new epoch is minted by a read.

An operator must separately authenticate installed source, standing ancestry,
controller lifetime and current host evidence before adopting a package. The
successor standing config must be derived from the exact G6 standing bytes,
retain controller/Hub/proof references, and explicitly name the old G6 source
and standing hashes in the two `g6_predecessor_*` fields. Both future Cold and
Guardian unit bytes must agree with the successor source. Installing only the
Guardian unit would leave the old future Cold source expecting a different
Guardian unit. No standing config or installer is shipped here.

The fixture in `tests/fixtures/g6-real-newboot` contains three gzip-compressed,
unaltered PUBLIC originals from one actual later-boot controller lifetime.
`MANIFEST.json` binds the decompressed bytes. `CAPTURE-PROVENANCE.json` records
the read-only capture separately from assertions. The fixture is historical;
its boot, handles, clocks and identities are never production inputs or a claim
about live current health. Tests also exercise identity, authority, reference,
hash, native handle/AST, echo/adoption and current15-expiry refusals. Native I/O
is simulated at the explicit test boundary; CI never invokes host operations.
