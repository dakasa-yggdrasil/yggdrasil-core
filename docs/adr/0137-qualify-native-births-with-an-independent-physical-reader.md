# ADR-0137: Qualify Native births with an independent physical reader

- **Status:** Proposed
- **Date:** 2026-11-27
- **Deciders:** Giomaster
- **Scope:** Core / Native physical creation qualification
- **Supersedes:** None
- **Superseded by:** None

## Context

Private custody of a provider return proves what was received, rather than what
currently exists. A creator, bootstrap process, Node label or read-only pricing
collector must not manufacture a physical birth, useful capacity or an admission
right. The actual immutable Launch already belongs to the Core child ledger.

## Decision

Add optional `physical_observers` to the Native lifecycle binding. Each profile
selects an independently protected read-only integration instance, exact instance
and type checksums/version, compiled SDK source and whole reviewed binding-file
SHA256. The instance must differ from every execution and pricing instance.
The only dispatched operation is `observe_native_worker` with four selectors
derived from archived Core state and its original acceptance. No workflow or
public HTTP route can select these bindings or submit a physical observation.

Qualify an AWS creation only after the original private return has committed.
Decode its bounded AWS57 transport envelope and complete RunInstances XML without
duplicate, aliased, foreign-namespace, DTD or extra-root interpretation. Join the
original semantic identity and request ID to the AWS58 independent complete
account, instance, subnet, security, encrypted disposable root and interface
read bracket. Ancillary root-volume and ENI IDs are compared when the pending
original explicitly contains them; missing IDs are not fabricated. Malformed or
present-empty IDs are refused, and complete current root/interface facts remain
mandatory. An error, partial return or missing original identity remains
unqualified; a successful later read cannot invent an earlier acceptance.

Reconstruct System's exact public Binding field order from the canonical stored
Launch and actual provider facts. Validate the public System context and
provider-specific identity before computing its digest. A producer-supplied
binding digest, label echo or bootstrap receipt is not accepted as this proof.
Raw provider bytes and their raw digest remain private original custody.

The first-ACK qualifier yields only `acknowledged`. A separate `ReobserveACK`
requires an existing sealed Physical and Birth, preserves the real lifecycle
state and returns only the identical physical tuple after the same fresh joins.
It cannot reopen first-ACK qualification or mint a phase permit. Neither qualifies a
Node, network warmup, registry membership, readiness, useful scheduling, drain
or absence. Root process composition supplies existing authority, Prepare and
post-ACK phase ports separately; no process flag, API or runtime is activated.

## Consequences

Absent optional bindings preserve the existing policy wire and behavior. New
Source-bound callback composition is required before this reader can be used.
The first concrete decoder and public fact DTO support AWS only. HCloud has
different project, location and action/request evidence; its empty account ID
and missing HTTP request IDs must never be filled with AWS-style inventions.
Its later typed qualifier remains an explicit separate implementation.

The complete provider and System protocols, strict rejection cases, original
privacy and protected reader selection are verified only by CI. This Source
delivery performs no provider request, purchase, bootstrap or cluster mutation.
