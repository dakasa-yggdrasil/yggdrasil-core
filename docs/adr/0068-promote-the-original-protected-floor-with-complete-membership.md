# ADR-0068: Promote the original protected floor with complete membership

- **Status:** Proposed
- **Date:** 2026-10-21
- **Scope:** First original Guest zero-to-one floor completion

## Context

The first protected Guest starts with a native empty inventory and has no
Demand300 history. Requiring that new endpoint to produce five minutes of
demand before promotion exceeds the original completion budget and lease.
Missing demand still cannot represent zero pressure or authorize expansion
or retirement.

## Decision

Allow only the source-owned zero-to-one protected floor generation to complete
with the actual complete Coverage30 response. Revalidate that exact bound raw
response at the transaction's PG time. Require the original claim's durable
empty baseline, matching current native profile identity, a live original
lease/fence and the existing provision graph. Keep every current-source,
compiled-approval, native tuple, original ledger and raw useful-canary gate in
the same phase transaction.

Retain the actual demand assessment without modification. Ordinary expansion
and retirement still require complete Demand300. This exception grants no
additional mutation, renewal, replay, timeout or caller-provided readiness.
It does not apply to recovery, degraded floors, nonempty baselines, terminal
generations, other source modes or generic legacy capacity paths.

## Consequences

The first useful member can become the protected floor before demand matures.
Capacity above that floor remains held until actual complete demand exists;
the stable epoch's original canary maintenance remains available meanwhile.
An absent or partial coverage range, missing useful receipt, expired owner or
uncertain provider operation still holds the transition.
