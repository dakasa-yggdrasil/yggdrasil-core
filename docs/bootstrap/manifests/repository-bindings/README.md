# Repository Bindings

Repository bindings connect ecosystem components to source repositories so the core can observe them,
and so Heimdall can target bounded workflow dispatches against the right repo.

Current bootstrap manifests:
- `action-emit-workflow-run.json`
- `integration-heimdall.json`
- `yggdrasil-auth-surface.json`
- `yggdrasil-console.json`
- `yggdrasil.json`
